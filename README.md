# Data Professional Survey Dashboard

#### Overview

This project presents an interactive Power BI dashboard built using a Data Professional Survey dataset. The dashboard provides insights into respondents’ demographics, career transitions, salary trends, work-life balance, job satisfaction, and programming language preferences.

The goal of this project is to transform raw survey data into meaningful business insights through effective data visualization and storytelling.

⸻

#### Dashboard Highlights

**Key Metrics**
	•	Total Survey Participants: 38
	•	Average Age: 29.21
	•	Average Work-Life Balance Rating: 5.92 / 10
	•	Average Salary Satisfaction Rating: 4.34 / 10

⸻

**Visualizations Included**
1. Country of Survey Takers
Treemap showing distribution of respondents by country.

2. Favorite Programming Language
Bar chart comparing most preferred programming languages among respondents.

3. Career Switch into Data
Chart displaying how many respondents transitioned into the data field.

4. Difficulty to Break into Data
Donut chart representing respondents’ opinions on entering the data industry.

5. Average Salary by Job Title
Horizontal bar chart comparing salaries across data-related roles such as:
	•	Data Scientist
	•	Data Engineer
	•	Data Architect
	•	Data Analyst
	•	Database Developer

6. Satisfaction Scores
Gauge visuals displaying:
	•	Work-Life Balance
	•	Salary Happiness

**Business Insights**
	•	Python is the most preferred programming language.
	•	Data Scientists reported the highest average salary.
	•	Many professionals switched careers into data roles.
	•	Salary satisfaction is lower than work-life balance satisfaction.
	•	Breaking into data is considered moderately difficult by many respondents.
